Sharing

Sharing always runs as the signed-in user, so nobody can share something they do not already have access to. Switching a capability off hides it and refuses it at the API.

Guests that were already here

Most tenants already have external accounts nobody can account for. Adoption gives each one an owner and an end date. It never blocks or removes anybody: the ordinary reminders and grace period take it from there.

Cleaning up inactive guests

Needs Entra ID P1 or P2 for sign-in data. Where that data is missing, nothing is done: a missing licence must never be read as evidence that somebody never signed in.

Safety limits

If a run would exceed a limit, everything pauses and waits for an administrator, rather than acting on hundreds of people because of one mistake.
